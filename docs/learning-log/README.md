# 학습 로그 (사람별)

- 한 사람 = 파일 하나. **자기 파일만** 고친다
	- `jongeume.md`
	- `eunah08.md`
- 하루를 마칠 때 자기 파일 **맨 아래**에 그날 칸(`## Day N - YYYY-MM-DD`)을 붙인다
- 칸 양식은 저장소 루트의 [`LEARNING_LOG.md`](../../LEARNING_LOG.md) 를 따른다
- 동료 코드나 AI 제안을 보기 **전에** 내가 시도한 내용을 먼저 적는다

## 충돌이 나지 않는 이유

- 사람마다 파일이 달라서, 각자 브랜치를 `dev` 로 병합해도 같은 줄을 두 사람이 고치는 일이 없다
- 남의 파일을 고치면 충돌이 날 수 있다 → 남의 기록에 덧붙일 말은 팀코어에서 말로 한다
